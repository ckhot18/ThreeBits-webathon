# ShikayatTrack

## Project Description

ShikayatTrack is a web app that helps citizens report local civic issues, track complaint status, and improve communication between residents and authorities.

## Tech Stack

- React
- Vite
- Firebase
- React Router
- Leaflet

## Setup

```bash
npm install
```

Create a `.env` file in the project root and add your Firebase / API keys.

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
